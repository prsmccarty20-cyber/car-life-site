# 運営者情報・広告について

## 運営者
{{ site.author }}

車の維持費やカー用品について、初心者の目線で調べたことを整理して紹介しています。

## このサイトの書き方
- 公式サイトなど、確認できる情報をもとに書いています。参考にした情報は、記事の最後に確認日と一緒にのせています。
- 自分で使ったものは「使ってみた」と書き、調べただけのものは「調べた」と分けて書きます。
- 価格やサービス内容は変わることがあります。申し込みや購入の前に、必ず公式サイトで最新の情報を確認してください。

## 広告について
このサイトでは、アフィリエイトプログラム（紹介した商品やサービスが購入・申し込みされると、運営者に報酬が入るしくみ）を利用することがあります。広告を含む記事には、記事の最初にその旨を表示します。
